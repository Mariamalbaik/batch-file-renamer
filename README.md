# Batch File Renamer

A simple Python script to rename all files in a folder in bulk.

## Features
- Renames all files in a folder at once
- Adds a custom prefix and sequential numbers
- Keeps original file extensions

## Requirements
- Python 3.6 or higher

## How to Run
1. Open terminal in the script folder
2. Run: python rename_files.py
3. Enter the folder path and desired prefix
